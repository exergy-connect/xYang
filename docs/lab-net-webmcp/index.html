To let a local agent update this page:
  1. Open chrome://inspect/#remote-debugging and turn on Enable remote debugging.  
  2. Connect Cursor with a local Chrome MCP server: npx chrome-devtools-mcp@latest --autoConnect --category-experimental-webmcp.
  3. Allow Chrome's connection prompt, then ask the agent to call submit_topology on this tab.

          
To enable WebMCP in Chrome:
  1. Paste chrome://flags/#enable-webmcp-testing into the address bar.  
  2. Set the flag to Enabled and relaunch Chrome.
  3. Return to this page and reload it.
If the flag is unavailable, update Chrome. See Chrome's instructions.
